Bierdeckel

Dein Deckel mit Freunden

Wer hat wem was geliehen? Nur auf euren Handys gespeichert, ohne Konto. Jede Änderung braucht das OK der anderen Person.

App herunterladen (Android)

So geht's

  1. Tippe auf App herunterladen.
  2. Öffne die heruntergeladene Datei und tippe auf Installieren. Fragt dein Handy, ob dein Browser Apps installieren darf, erlaube es einmal.
  3. Öffne Bierdeckel und gib deinen Namen ein.
  4. Tippe auf Freund hinzufügen → Code des Freundes scannen und scanne den Code auf dem Handy deines Freundes.
  5. Dein Freund tippt auf Annehmen. Fertig, ihr seid verbunden.

iPhone? Öffne stattdessen die Web-Version in Safari und füge sie über Teilen → „Zum Home-Bildschirm“ hinzu.
